# my-blog

A personal blog and a bilingual daily AI brief. Long-form writing and the daily brief are separate kinds of content that share a site.

## Language

### The daily brief

**Issue**:
The brief for one language on a given day — the thing a reader opens and the thing a page renders. Carries the Issue number, which it shares with its Companion.
_Avoid_: digest (that is the file it is authored in), edition, post

**Digest**:
The authored `.mdx` source file behind an Issue, and its Velite record. One Digest per language per day.
_Avoid_: article, entry

**Companion**:
The Issue for the same day in the opposite language. An Issue has at most one, and most days have none.
_Avoid_: translation, sibling, pair

**Issue number**:
The brief's running count, assigned per day in publication order. Both languages of a day share one number, so the number identifies the day rather than the Issue.
_Avoid_: issue id, index

**Volume**:
The calendar year the brief is running in, displayed as a Roman numeral on the masthead. Independent of the Issue number, which never resets.
_Avoid_: year, series

## The blog

**Post**:
A long-form article, authored as `.mdx`. Unrelated to the daily brief and not numbered.
_Avoid_: article, blog, entry
